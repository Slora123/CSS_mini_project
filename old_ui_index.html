Objective

Message Authentication Code (MAC)

The primary objective of this experiment is to implement, analyze, and verify a Message Authentication Code (MAC) for arbitrary messages using a shared secret key K. Students will explore how MAC provides data integrity and data origin authentication, and observe how an attacker who modifies the message but cannot forge a valid MAC is detected by the receiver.

Theory

Theory & Concepts

A Message Authentication Code (MAC) is a symmetric key cryptographic algorithm that takes an arbitrary-length message payload and a shared secret key, and produces a fixed-size authentication tag.

Only parties who possess the secret key can compute or verify the tag. If an adversary modifies even 1 bit of the message but cannot recompute the MAC (because they don't have the key), the receiver's verification algorithm detects the tampering.

Security Properties

Unlike a simple Cryptographic Hash, a MAC requires a shared secret key, preventing attackers from regenerating a valid tag after tampering. Unlike Digital Signatures, MAC does not provide non-repudiation because both parties share the same key.

Procedure

Algorithm Flow

  1. Sender Side: The sender enters a message and a secret key. The MAC algorithm generates a tag. The sender transmits the message appended with the MAC.
  2. Attacker (Man-in-the-Middle): An attacker intercepts the transmission, modifies the message, and must generate a forged MAC using a random key (since they don't know the secret key).
  3. Receiver Side: The receiver uses the shared secret key to compute the MAC on the received message. If it matches the received tag, it is authentic; otherwise, tampering is detected.
